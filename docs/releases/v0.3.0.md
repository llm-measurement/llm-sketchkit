# llm-sketchkit 0.3.0

0.3.0 corrects text normalization and tightens summary validation. **Some
identities change when upgrading from 0.2.x, in Go as well as Python.** Go 1.26
or newer is required; Python 3.11 or newer remains supported.

## Text Identities

The Go dependency update from `golang.org/x/text` 0.41.0 to 0.42.0 fixes an
upstream composition-key bug. For example, U+11F41 followed by certain combining
marks could incorrectly become unrelated Greek text. Correcting normalization
changes the resulting hashes. Check the resolved dependency version in each
build: other modules can select a newer version than sketchkit's minimum.

Python `text_v1` now matches Go's exact Unicode White_Space trimming and
stream-safe NFC behavior:

- U+001C through U+001F at text edges are preserved instead of stripped.
- Runs exceeding 30 non-starters receive U+034F COMBINING GRAPHEME JOINER.
  Counting includes compatibility decompositions and backward-combining
  characters, so fewer than 31 original characters can reach the limit.
- Python 3.11 uses the correct combining classes for Unicode 15 marks.

The cross-language guarantee covers Unicode 15.0 assigned scalars, including
private-use values. Unassigned values, noncharacters, and later additions remain
outside that boundary. Invalid UTF-8 remains an error.

## Retained State

Profile names and wire formats are unchanged, so merge checks cannot identify
mixed old and corrected identities. Retained hashes or sketches alone cannot
be repaired.

Upgrade affected producers at a new observation-window boundary. Keep affected
old and new windows separate in comparisons and merges. Rebuild only from
legitimately available original inputs, using one normalizer version/build and
the original hash key. Otherwise retain a separate historical series. See the
[identity migration guide](../IDENTITY_MIGRATION.md) for affected inputs and the
full procedure, including Go-only deployments using the older dependency.

## Estimates And Validation

Python HLL++ bias sums use left-to-right addition. On Python 3.12 and later,
estimates may differ in their last bits. Stored registers, sketch bytes, and
hash identities are unchanged by this estimate correction.

Both languages reject zero-length observation intervals containing nonzero
counters or nonempty sketch state. Configured empty sketches remain valid,
including all-zero dense HLL++ state. Tied epoch starts sort by end time, then
epoch identifier. Protobuf groups are rejected before decoding; the schema
defines none.

This release also includes bounded parser allocation, reduced repeated work
when combining summaries, and safer secret handling in diagnostics. See
[operations](../OPERATIONS.md) for resource limits. Test retained summaries and
external encodings before upgrading.
